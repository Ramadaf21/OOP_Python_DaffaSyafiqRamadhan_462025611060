# Final Project OOP - RPG Battle Arena

## Deskripsi

RPG Battle Arena adalah aplikasi berbasis terminal yang dibuat sebagai Final Project mata kuliah Object-Oriented Programming (OOP).

Aplikasi ini mensimulasikan pertarungan sederhana antara Player dan Musuh dengan menerapkan berbagai konsep OOP.

## Konsep OOP yang Digunakan

Aplikasi menerapkan:

1. Encapsulation
2. Inheritance
3. Multiple Inheritance
4. Polymorphism
5. Method Overriding
6. Duck Typing
7. Magic Methods
8. Instance Methods
9. Static Method
10. Exception Handling
11. Custom Exception

## Fitur

* Membuat Player dengan role Defender, Attacker, atau Hybrid
* Melihat status Player dan Musuh
* Menyerang Musuh
* Damage Retribution
* Menggunakan Pedang
* Menggunakan Panah
* Menggunakan Sihir
* Validasi damage
* Penanganan error menggunakan Exception Handling

## Cara Menjalankan

Pastikan Python sudah terinstall.

Masuk ke folder Final_Project:

```bash
cd Final_Project
```

Kemudian jalankan:

```bash
python main.py
```

## Requirements

Program menggunakan Python Standard Library dan tidak membutuhkan library eksternal.

Python yang direkomendasikan:

Python 3.10 atau lebih baru.
